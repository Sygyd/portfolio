# Portfolio de Ingeniería de Sistemas - Luis Martinez

Portafolio de arquitectura de software y sistemas distribuidos de alto impacto, enfocado en resiliencia, alta disponibilidad, seguridad Zero-Trust y automatización con IA (ROI comprobable).

## Stack Tecnológico
- **Framework**: Next.js 15 (App Router), React 19
- **Lenguaje**: TypeScript en modo estricto
- **Estilos**: Tailwind CSS, CSS Variables con paletas de alto contraste
- **Microinteracciones**: Framer Motion & CSS hardware-accelerated transforms
- **Gestión de Temas**: `next-themes` con 4 temas técnicos (`obsidian`, `terminal`, `nordic`, `studio`)
- **Internacionalización**: Capa i18n reactiva sin recargas con soporte Español / Inglés

## Proyectos Enterprise Presentados
1. **El Mulato Cabaret**: Real-Time WebSockets, Multimodal AI & CRM Serverless.
2. **Puerto Aventura Gestor**: Multi-Tenant B2B SaaS, Zero-Trust RLS, Next.js & PropTech.
3. **Tellex Group**: Enterprise QA Auditing, Workforce Analytics & BI Platform.

## Ejecución Local
```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) en el navegador.

## Despliegue en Vercel
El proyecto está 100% optimizado para compilación estática y Serverless Edge deployment en Vercel.
